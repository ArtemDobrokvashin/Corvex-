# mail-pop3-service

POP3 (RFC 1939 + STLS RFC 2595) для устаревших клиентов: порты 110 (STLS) / 995 (TLS).

- Протокольный движок — **Apache James POP3 protocol library** за портом-адаптером
  (аналогично IMAP-сервису, профиль сборки `james`); собственный парсер не пишется.
- Семантика поверх общего хранилища: видна только папка INBOX, `UIDL` = стабильный
  хэш от (`message_metadata.id`), `DELE` помечает письмо удалённым и физически удаляет
  на `QUIT` (в соответствии с RFC), опция «оставлять копии на сервере» — настройка клиента.
- Аутентификация и app-passwords — как в IMAP, через `auth-service`.
- POP3 включён по умолчанию, но админ может отключить его глобально
  (`ADMIN_MAIL_POLICY`, настройка `mail.pop3.enabled`) — протокол без синхронизации
  флагов/папок рекомендуется только как переходный.
