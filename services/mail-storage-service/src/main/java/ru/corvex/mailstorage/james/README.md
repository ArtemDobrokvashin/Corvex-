# Незавершённый клиент James JMAP

Экспериментальный код без регистрации в Spring и без подключения к API, не
развёрнут и не предназначен для production. Вызовы ограничены операциями чтения,
используют фиксированный HTTPS origin, не следуют redirect и не логируют токен.
Это только транспорт: он не проверяет JWT Corvex, не выдаёт токены James, не
связывает accountId с owner UUID и не обеспечивает RBAC, AV, TTL или отзыв.
Нельзя открывать этот клиент через API или направлять в него пользовательские
параметры до реализации и испытания этих механизмов.

Java-синтаксис проверен отдельно. Maven/JUnit, фактический HTTPS, таймауты при
медленном чтении и живой James не проверены. Отдельно необходимо ограничить время
чтения тела HTTP-ответа: таймаут запроса не должен считаться доказательством
ограничения `InputStream` после получения заголовков. Код опубликован в рабочей ветке для лабораторной проверки; не включать в
работающий сервис, пока эти проверки не пройдены на изолированном стенде.

`JamesMailboxBinding` — экспериментальная проверка согласованности UUID,
права чтения, активного серверного сопоставления и первичного аккаунта сессии.
Она не создаёт и не подтверждает достоверность этих сведений, не проверяет
подпись токена и не предотвращает отзыв во время операции. Требуются безопасный
реестр сопоставлений, актуальный статус/права, выпуск отдельного токена James,
связывание его с полученной сессией и интеграционные испытания. Не подключена
к API и не означает переноса или миграции почты.
