# Кандидат внутреннего read-only JMAP gateway

Текущий nginx на `/jmap` не проверяет содержимое POST, поэтому bearer-токен с
сетевым доступом позволяет попытаться выполнить `Email/import`, минуя spool AV.
Этот кандидат принимает только `GET /jmap/session` и один POST-вызов из
`Mailbox/get`, `Email/query`, `Email/get`. Пакеты из нескольких вызовов,
операции записи, загрузка/выгрузка, другие URL, сжатое тело и неподдержанные
заголовки авторизации отвергаются. JSON разбирается и сериализуется заново,
чтобы duplicate keys или escape-последовательности не позволили другой
интерпретации переданной James команды. Размер тела, ответа и срок ожидания
ограничены. На стороне James он не следует redirect и не пишет токены в лог.

Запуск проверок: `node --test infra/james/jmap-read-gateway/gateway.test.cjs`
(Node 22). Это синтетический HTTP upstream, **не** настоящий James. Дополнительно
локально проверены HTTPS с временным сертификатом, правильным/неправильным
именем и недоверенным сертификатом; это не проверка реального сертификата
Corvex, Docker image или Java-клиента через этот gateway.

`infra/james/candidates/jmap-read-gateway.compose.yml` — выключенный overlay
для существующего сервиса `james-jmap`, не новый стенд и не Compose по
умолчанию. Он переопределяет image/build и использует уже смонтированные
сертификат и ключ. Docker/Compose merge, сборка, доступность файлов ключей,
замена действующего сервиса и восстановление nginx пока не испытаны; не
включать overlay для пользовательского трафика до совместной проверки и
подготовленного восстановления. Из-за добавления build к имеющемуся image
нужно явно проверить, какой image фактически использует Compose.

Ограничение методов — не авторизация пользователя. Bearer остаётся полноценным
токеном James, поэтому требуется доверенная привязка владельца, актуальный
RBAC, короткий срок и защита ключей. Доступ к самому James через другую сеть,
WebAdmin, IMAP APPEND или иные каналы этот gateway не ограничивает; в частности,
AV-overlay даёт сетевой доступ контейнеру ClamAV. Не выдавать токены браузеру.
Этот gateway не проверяет AV, не сохраняет письма и не является завершённым
переносом на James.
