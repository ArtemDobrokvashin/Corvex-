# Support / Поддержка

## Community support / Сообщество

- **Bugs and feature requests:** open a GitHub issue with the Corvex version/commit, deployment method, browser/OS, steps to reproduce, expected vs. actual result, and relevant **redacted** logs.
- **Deployment questions:** start with [`docs/INSTALL.md`](docs/INSTALL.md) / [`docs/INSTALL.en.md`](docs/INSTALL.en.md) and [`docs/READINESS.md`](docs/READINESS.md). Remember: production mail delivery is Stage 2, IMAP/POP3 is Stage 3, persistent chat is Stage 4.
- **Adoption records:** deployments may optionally be recorded in [`ADOPTERS.md`](ADOPTERS.md) or reported privately. Corvex has no hidden telemetry and collects no deployment statistics.

Never post passwords, refresh cookies, JWTs, TOTP secrets, private keys, mail contents, personal data, or unredacted infrastructure details.

## Security reports / Сообщения о безопасности

Please do not publish exploitable vulnerability details in a public issue. Contact the author privately first:

**Artem Dobrokvashin — https://t.me/Artem_Dobrokvashin**

Include affected component/version, impact, and a minimal reproduction. Do not include real user mail or secrets.

## Commercial contact and donations / Коммерческая связь и пожертвования

Corvex is currently free of charge for self-hosted deployment. Paid deployment assistance, migration planning, training, priority bug fixes, custom integrations, and future priority support can be discussed directly with the author. Voluntary donations are likewise arranged directly on Telegram; payment details are intentionally not published in the repository.

Commercial scope, price, response times, invoices, and written license terms are agreed individually until a public support/enterprise offering is published.
