## 6. Мобильное приложение — честно

К утру в ветке `arena/67475b8c-corvex` (PR #360) лежит:

- палитра и типографика как в вебе (`ui/theme/`);
- новый список писем: точка непрочитанного, аватар, отправитель, тема, превью, время;
- экран чтения письма (`ui/mail/MailDetailScreen.kt`);
- ресурсы, которых раньше не было вообще: `strings.xml`, `colors.xml`,
  `themes.xml`, адаптивная иконка;
- сторожа: `test_android_resources.py` (5 тестов) и прежний `test_android_hilt_wiring.py`.

**Чего нет — и это главное.** Приложение **не собиралось**: в репозитории нет
`gradlew` и `gradle-wrapper.jar`, а скачать их неоткуда — хосты Gradle и Maven
закрыты. Поэтому «дизайн обновлён» значит «код написан и проверен чтением и
сторожами», а не «приложение запускается».

**Что сделать тебе — 3 минуты, один раз.** Самый простой путь, без установки
Android Studio:

```powershell
# 1) любой JDK 17 (если уже есть — пропустить): winget install EclipseAdoptium.Temurin.17.JDK
# 2) скачать Gradle 8.10.2: https://services.gradle.org/distributions/gradle-8.10.2-bin.zip
#    распаковать, например, в C:\gradle-8.10.2
cd C:\corvex\android
C:\gradle-8.10.2\bin\gradle.bat wrapper --gradle-version 8.10.2 --distribution-type bin
git add gradlew gradlew.bat gradle/wrapper/gradle-wrapper.jar
git commit -m "android: gradle wrapper"
git push
```

После этого:

```powershell
cd C:\corvex\android
.\gradlew.bat testDebugUnitTest assembleDebug
```

APK появится в `android\app\build\outputs\apk\debug\`. Его можно поставить на
телефон (`adb install`) и посмотреть, как выглядит новый интерфейс.

Затем вставить джобу Android из [`ci/android-job.yml`](ci/android-job.yml) в
`.github/workflows/ci.yml` — и мобильные изменения перестанут быть непроверенными.
